1. **mark-board는 무한 캔버스 위의 노드 하나가 plain text가 아니라 마크다운 문서인 로컬 설치형 앱이고, 캔버스가 먼저이며 마크다운은 노드의 콘텐츠 형식이다.**
   1. Apple Freeform과 다른 점은 노드가 마크다운 문서라는 것이다. 노드는 렌더된 마크다운을 보여주고, 편집으로 들어가면 마크다운 소스가 된다.
   1. 마크다운 vault 위에 캔버스를 얹는 구조가 아니다. 캔버스가 먼저이고 마크다운은 노드가 담는 형식이다. 그래서 JSON Canvas 1.0 스펙을 데이터 모델의 뼈대로 채택하지 않는다. vault 상호운용이 목표가 아니므로 남의 스펙에 데이터 모델을 묶지 않고, 내보내기가 필요해지면 그때 대응 포맷으로 꺼낸다.
   1. 마크다운을 노드 형식으로 못 박은 결과 캔버스 렌더는 DOM 계열로 강제된다. 마크다운을 canvas에 그리려면 텍스트 레이아웃·줄바꿈·인라인 요소를 직접 구현해야 하기 때문이다. 그래서 캔버스는 React Flow(`@xyflow/react`, MIT)를 쓰고, 노드가 React 컴포넌트라 마크다운 렌더러를 그대로 삽입한다.
   1. 로컬에 설치해 매일 쓰는 것이 능력 증명이다. brew로 무료 설치하고 로컬 서버 + SQLite로 돈다. 검색·frontmatter·RAG 같은 AI 기능만 BYOK(사용자 키) 또는 유료로 제공한다.
2. **로직은 로컬 서버 하나가 소유하고, 웹 UI·CLI·MCP 세 표면은 전부 그 HTTP API의 클라이언트이며 저장소에 직접 붙지 않는다.**
   1. 세 표면 중 어느 것도 SQLite를 직접 열지 않는다. 서버 앱 밖에서 `node:sqlite`·`.db` 경로·테이블 이름이 등장하면 위반이다. 직접 열면 락 경합과 로직 중복이 동시에 생긴다.
   1. 웹 UI는 React + React Flow, 서버는 NestJS다. CLI와 MCP는 같은 HTTP API를 부르고, HTTP 클라이언트는 `packages/api-client` 한 곳에 두고 두 표면이 패키지 이름으로 가져온다.
   1. CLI는 읽기 명령(`worlds`·`nodes`·`search`·`cat`)과 쓰기 명령(`world new/rm`·`node new/edit/rm`), 그리고 서버를 띄우는 `mark-board serve`를 갖는다. 사람이 읽는 출력과 `--json`을 함께 낸다. 서버가 꺼져 있으면 스택 트레이스가 아니라 무엇을 해야 하는지를 보이고 종료 코드는 0이 아니다.
   1. MCP는 stdio로 같은 HTTP API를 도구로 노출한다. 단 답변 생성(`ask`)은 MCP에 주지 않는다. 부르는 쪽이 이미 모델이라 사용자 키를 두 번 쓰고 답의 근거가 한 겹 멀어진다. MCP는 근거를 주는 `search_nodes`까지다.
   1. 표현이 자주 바뀌는 것(외부 응답 구조, 저장소 컬럼명, provider별 파라미터)은 변환 경계 한 곳에 가둔다. 표현 하나를 바꿨을 때 고쳐야 하는 파일이 둘 이상이면 지식이 새는 것이다.
3. **노드의 마크다운 원문(`body_md`)이 유일한 원본이고, 검색·frontmatter 같은 색인은 전부 그 원본에서 파생한다.**
   1. 노드를 JSON 덩어리로 저장하지 않고 정규화한다. 검색·frontmatter 파이프라인·RAG가 요구사항이라 정규화가 필요하다. 스키마는 `worlds`·`nodes`·`edges`·`assets`와 파생 테이블들이다.
   1. frontmatter는 원본을 `body_md`에 그대로 두고 파싱 결과만 `node_meta`(EAV)에 파생으로 인덱싱한다. 분리 저장하면 마크다운으로 내보낼 때 원본을 재조립해야 하고 그 과정에서 키 순서·주석·포맷이 소실된다.
   1. "깨진 frontmatter"와 "frontmatter 없음"을 구별하려고 `node_frontmatter` 상태 테이블(`present`·`ok`·`error`·`parsed_at`)을 따로 둔다. 상태 테이블이 없으면 둘 다 `node_meta` 행 0개로 같아진다. "없는 것"과 "빈 것"이 같아지는 실패를 설계에서 막는다.
   1. 이미지 원본은 로컬 FS에 두고 DB에는 메타만(`assets`) 둔다. sha256 파일명으로 내용 주소화해 같은 이미지를 중복 저장하지 않는다.
4. **여러 개의 World 각각에 마크다운 노드를 만들고 편집·이동·저장·복원하며, 캡쳐 이미지와 코드 블록을 붙여넣을 수 있다.**
   1. 노드는 더블클릭하면 마크다운 소스 편집으로 바뀌고 벗어나면 렌더로 돌아온다. 렌더 상태에서 드래그하면 노드가 이동하고, 편집 상태에서 드래그하면 텍스트가 선택된다. 저장은 디바운스하고, 서버를 껐다 켜고 새로고침해도 노드 위치와 본문이 그대로 복원된다.
   1. World를 여러 개 만들어 목록·전환·생성·이름 변경·삭제하고 마지막으로 연 World를 기억한다. World를 전환하면 각 캔버스의 노드와 뷰포트가 독립으로 복원되고, World를 지우면 그 안의 노드가 함께 사라진다(CASCADE).
   1. 클립보드 이미지를 붙여넣으면 업로드되어 로컬 FS에 내용 주소로 저장되고, 마크다운 이미지 문법으로 본문에 삽입되어 렌더되며 재시작해도 복원된다.
   1. 코드 블록은 붙여넣은 원문을 편집기가 보존하고 fenced 마크다운으로 렌더한다. plain text가 코드인지 신뢰성 있게 가를 신호가 없어 자동 fencing은 넣지 않는다.
5. **노드 본문 검색은 질의 길이로 경로를 가른다. 3자 이상은 FTS5 trigram의 `MATCH`와 `bm25()` 순위로, 3자 미만은 같은 테이블의 색인된 `LIKE`로 답하고, 결과를 누르면 그 노드로 캔버스가 이동한다.**
   1. 한국어가 이 라우팅을 만든다. 한국어는 어절 단위로 띄되 조사가 붙어서, 기본 unicode61 토크나이저는 `캔버스에서`를 한 토큰으로 잡아 `캔버스`로 못 찾고, trigram은 3자 미만 질의를 구조적으로 못 받는다. 같은 trigram 테이블이 색인된 `LIKE`를 지원하므로 2자 이하는 `LIKE`로 폴백한다. 대가는 `LIKE` 경로에 `bm25()` 순위가 없다는 것이다.
   1. `bm25()`는 음수를 돌려주고 값이 작을수록 좋은 매치다. 정렬 방향을 반대로 쓰면 최악의 결과가 위로 온다. 정렬에는 `rank` 컬럼을 쓴다.
   1. 검색 색인은 `nodes.body_md`에 대한 FTS5 external content 테이블이고 동기화는 사용자가 책임진다. INSERT·DELETE·UPDATE 트리거 3개로 맞추고, 어긋나면 `'rebuild'`로 다시 만든다. 본문을 고치고 곧바로 검색하면 바뀐 내용으로 찾혀야 한다.
   1. 테이블을 라틴용·CJK용으로 나누지 않는다. 로컬 단일 사용자에 문서 수천 규모라 trigram 하나 + `LIKE` 폴백으로 충분하고, 나눌 필요가 증명되면 그때 나눈다.
6. **AI 기능은 프로바이더 중립 BYOK로 가고, 키가 없거나 프로바이더가 죽어도 나머지 기능은 degrade하며 멈추지 않는다.**
   1. AI 계층은 Vercel AI SDK v7(`ai@7` + `@ai-sdk/*`)로 프로바이더를 추상화한다. 구조화 출력은 `generateText`에 `Output.object({ schema })`를 줘서 프로바이더를 가로질러 정규화한다. 특정 벤더 SDK를 직접 쓰지 않는 대가로 그 벤더 고유 기능을 포기하고, 얻는 것은 "사용자마다 프로바이더가 다름"이라는 제품 요구다.
   1. frontmatter 생성은 노드 하나를 받아 제안된 frontmatter를 낸다. 사용자가 승인하기 전에는 노드 본문을 바꾸지 않는다. 키를 넣지 않은 채 부르면 "키가 없다"가 사람 말로 보이고, 넣으면 동작한다.
   1. RAG는 `POST /api/ask`로 검색 결과를 컨텍스트로 답을 만들고 출처 노드를 함께 돌려준다. 근거가 0개면 모델을 부르지 않는다(`answer: null`, 호출 0). 빈 컨텍스트가 환각의 가장 흔한 입구라 호출 경로 자체를 없앤다. 인용은 평문 안의 `[n]`으로 받고 서버가 번호 범위를 검사해 없는 번호는 버린다.
   1. 의미 검색은 노드 본문 임베딩을 BLOB으로 저장하고 전수 코사인 top-k로 찾아, 기존 키워드 검색과 RRF(`Σ 1/(60+순위)`)로 합친다. 점수 정규화로 가지 않은 이유는 `LIKE` 경로에 점수가 아예 없어서다. 벡터 레인은 덧붙이는 것이지 전제가 아니라, 키가 없거나 프로바이더가 죽어도 검색은 200이고 키워드 결과가 그대로 나간다.
   1. 임베딩 자격증명은 채팅과 별도다. 모델·차원·키가 다르고, 어떤 프로바이더는 임베딩을 아예 주지 않는다. 본문이 바뀌면 임베딩을 즉시 다시 계산하지 않고 낡음으로 표시한 뒤 나중에 채운다. 임베딩은 돈과 네트워크가 들어 저장 트랜잭션 안에서 호출할 수 없기 때문이다.
   1. BYOK 키는 로그·API 응답·검색 색인 어디에도 나타나지 않는다. `~/.mark-board/credentials.json`에 두고, 파일 권한이 `0600`보다 느슨하면 서버가 거절한다.
7. **로컬 토큰이 HTTP API 전체를 가리고, CORS는 접근 제어가 아니다.**
   1. CORS를 좁힌 것으로 API가 보호된다고 읽지 않는다. CORS는 브라우저가 페이지 JS에 응답을 보여줄지 정하는 규칙일 뿐이고, CLI·MCP는 브라우저가 아니라 CORS를 아예 읽지 않는다. 세 표면 중 둘이 그 규칙 밖에 있다.
   1. 토큰은 부팅에 없으면 `~/.mark-board/token`에 `0600`으로 발급하고, 권한이 느슨하면 부팅하지 않는다. 토큰 없이 API를 부르면 401이다. CLI·MCP는 `packages/local-token`이 읽어 `Authorization: Bearer`로 붙인다.
   1. 웹은 토큰을 쥐지 않는다. 마크다운 이미지가 `<img src="/api/assets/…">`라 헤더를 붙일 수 없어서, 서버가 문서를 줄 때 `HttpOnly; SameSite=Strict; Path=/api` 쿠키를 심는다. 개발에서는 Vite 프록시가 `/api`에 Bearer를 붙여, 브라우저는 배포와 똑같이 토큰을 모른다.
   1. 쿠키는 포트로 격리되지 않아 `SameSite=Strict`만으로 CSRF가 안 닫힌다. 그래서 쿠키로 인증할 때만 `Sec-Fetch-Site`를 보고 `same-origin`·`none`만 통과시킨다. 브라우저가 만들고 스크립트가 위조할 수 없는 값이기 때문이다.
   1. 기기 밖을 막는 세 조치를 함께 닫는다. 기본 바인딩은 루프백(`127.0.0.1`)이고 LAN을 열려면 `MARK_BOARD_HOST`라는 명시적 문을 쓴다(기본값은 잠긴 쪽). body parser는 JSON만 켜서 폼 인코딩 POST(CSRF)를 400으로 막는다. `Host` 헤더는 낯선 이름을 403으로 막되 IP 리터럴은 통과시켜 LAN 문을 살린다.
   1. 웹을 서버가 직접 서빙해 same-origin으로 만들면 CORS가 그림에서 사라진다. 이것이 토큰 주입과 나머지 보안 조치의 전제다.
8. **네 앱(서버·웹·CLI·MCP)을 설치본 하나로 묶어 brew로 설치하고, `depends_on "node"` + npm으로 나르며, PWA로 창에 설치한다.**
   1. 표면 넷은 배포 단위가 아니다. 따로 설치하면 버전이 어긋나므로 패키지 하나로 묶고, 레지스트리에 없는 workspace 패키지는 `bundleDependencies`로 나른다.
   1. formula는 설치본에서 생성한다. `url`과 `sha256`을 손으로 옮기면 테스트한 파일과 배포하는 파일이 갈릴 수 있다.
   1. 네이티브 모듈이 하나도 없어서(SQLite가 `node:sqlite` 코어다) `depends_on "node"` 하나로 끝난다. 단일 바이너리(SEA)는 설치 경험이 실제 문제가 됐을 때 간다.
   1. PWA는 manifest + 아이콘이고 service worker는 넣지 않았다. 브라우저가 설치 요건에서 뺐기 때문이다.
9. **다음은 이 앱이 지금 하지 않는 것이고, 각각 왜 미뤘는지가 함께 정해져 있다.**
   1. 실시간 동시 편집을 하지 않는다. 사용자마다 자기 World를 갖고, 오프라인이 필수 요구가 아니라 충돌 해결 비용(CRDT)을 지금 사지 않는다. 서버 우선 + 낙관적 업데이트 + 디바운스 저장으로 가고, 범위가 바뀌면 되살린다.
   1. 마크다운만 지원한다. 이미지도 마크다운 이미지로 들어간다.
   1. 벡터 검색 결과에 바닥이 없어 무관한 질의에도 최근접 k개가 나오고 "결과 없음"이 사라진다. 지금은 아무것도 자르지 않고 `similarity`를 응답에 실어 소비자가 스스로 자르게 둔다. 자르는 방법마다 대가가 달라 답변(RAG) 완성 시점에 다시 본다.
   1. 노드 id를 서버가 만들어(`crypto.randomUUID()` v4) 노드 하나를 만들 때 서버 왕복 지연이 보인다. 클라이언트 생성으로 옮길지, 옮기면 v4로 충분한지 v7이 필요한지는 순서대로 판단한다.
   1. 제품 페이지·try-out·결제는 아직 이름만 있다. 호스팅되는 제품이라 로컬 설치형의 전제(루프백·로컬 토큰·파일 권한)를 다시 정해야 한다.
   1. 검증을 zod로 옮길지, BYOK 키를 OS 키체인에 둘지는 조건이 되면 다시 꺼내기로 미뤄 뒀다.

## TL;DR
- OpenCut은 서버 전송 없이 브라우저에서만 동작하는 오픈소스 영상 편집기이나, AI 에이전트 연동(MCP·headless)은 아직 로드맵 단계다.

## 핵심
- OpenCut은 2025년 6월 시작된 **오픈소스 브라우저 영상 편집기**로, CapCut의 유료화·데이터 수집 경로와 정반대 모델을 지향한다. 영상·오디오 파일을 서버에 올리지 않고, 편집과 렌더링을 모두 브라우저 안에서 처리하는 것이 핵심 차별점이다.
- 이 로컬-온리 구조는 **IndexedDB**에 프로젝트 메타데이터만 저장하고, AI 자동 캡션조차 기기 내 추론으로 처리함으로써実現된다. MP4 내보내기는 **FFmpeg.wasm**이 담당한다.
- 2026년 5월 팀은 TypeScript 기반 브라우저 엔진을 **Rust 코어로 전면 재작성**하겠다고 발표했는데, 목표는 단순 편집기가 아니라 **Editor API · 플러그인 · headless 렌더링 · MCP 서버**를 갖춘 '프로그래밍 가능한 비디오 플랫폼'이다.
- 다만 저자는 MCP·headless·플러그인이 **완성된 기능이 아니라 로드맵**임을 명시한다. 현재 실사용 가능한 건 classic 버전뿐이며, MCP도 네이티브 구현 전이라 커뮤니티가 Playwright로 만든 서드파티 컨트롤러만 존재한다.

## 깊이
- **[트랙션 — 주장]** 저자는 GitHub 스타 71,964개·포크 7,367개(2026-07-16 기준)를 근거로 "트랙션이 진짜"라고 **주장**한다. MIT 라이선스가 페이월 방지 안전장치로 작동한다는 점도 함께 지적한다. → 스타 수는 GitHub에서 직접 확인 가능한 **사실**이나, 그것이 활성 사용자 수를 의미하는지는 **불확실**.
- **[재작성 아키텍처]** Rust 코어 통합의 핵심은 렌더링 파이프라인을 단일 엔진으로 통일하고, 그 위에 Editor API를 노출해 외부(AI 에이전트 포함)가 편집 세션을 프로그래밍으로 제어할 수 있게 하는 것이다. 이는 영상 편집을 'GUI 작업'에서 '코드 가능한 워크플로'로 전환하겠다는 의도로 읽힌다.
- **[CapCut 대비 모델]** 원문은 CapCut이 "무료 모집 → 유료 전환 → 사용자 콘텐츠로 AI 학습" 경로를 밟았다고 **주장**하며, OpenCut은 워터마크·구독·백엔드 콜이 없다고 대비시킨다. CapCut 측 정책은 원문에 상세 근거가 없어 **검증 필요**.

## 용어 풀이
- **MCP (Model Context Protocol)** — AI 에이전트가 외부 도구를 호출하는 표준 프로토콜 / 비유: "AI가 리모컨으로 편집기를 조작하는 규격" / 비유가 깨지는 지점: 리모컨은 단방향이지만 MCP는 컨텍스트 읽기·쓰기가 양방향이다.
- **FFmpeg.wasm** — FFmpeg를 WebAssembly로 컴파일해 브라우저에서 영상 인코딩을 처리하는 라이브러리 / 비유: "브라우저 안에 들어온 소형 영상 공장" / 비유가 깨지는 지점: 네이티브 FFmpeg보다 메모리·속도 제약이 크다.
- **Headless 렌더링** — UI 없이 명령줄·API로 배치 렌더링을 수행하는 모드 / 비유: "운전석 없는 자율주행 편집" / 비유가 깨지는 지점: 자율주행은 실시간 판단이지만 headless는 사전 정의된 스크립트 실행에 가깝다.
- **IndexedDB** — 브라우저 내 구조화 데이터 저장소 / 비유: "브라우저 전용 소형 창고" / 비유가 깨지는 지점: 창고는 영구적이지만 IndexedDB는 캐시 삭제·브라우저 초기화로 사라질 수 있다.

## 핵심 시사점 / 판단
- **(저자 주장)** OpenCut은 현재 "프라이버시 지키는 무료 CapCut 대안"이며, 장기적으로 "AI 에이전트가 조종하는 영상 자동화 플랫폼"을 지향한다.
- **(검증 필요·불확실)** Rust 재작성판의 실제 릴리스 시기와 MCP·headless 기능 완성도는 원문에 일정 정보가 없어 **불확실**. GitHub 스타 수가 실제 프로덕션 사용을 반영하는지도 **검증 필요**.
- **(검증 필요)** CapCut의 데이터 활용·유료화 경로에 대한 서술은 저자의 **주장**이며, 원문에 1차 근거 링크가 없다.

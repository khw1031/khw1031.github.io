## TL;DR
- 최신 LLM은 파라미터당 추론력을 극대화하는 대신 사실 지식을 의도적으로 줄이고, 그 지식을 runtime harness(검색·도구·문서)로 넘기는 설계 전환이 진행 중이며, 저자는 이것이 환각을 구조적으로 줄인다고 주장한다.

## 큰 그림
```
[파라미터 예산]
   ├── 사실 저장 (2 bit/param, 부패 빠름)
   │     └─→ weights에서 제거 ──→ 외부 harness로 이동
   │                                  ├── RAG / 검색
   │                                  ├── tool call
   │                                  └── 문서 파일시스템
   └── 추론 절차 (압축 잘 됨, 부패 안 함)
         └─→ distillation·RL로 소형 모델에 전이

결과: active param ↓ + 추론 벤치마크 ↑
      + 사실 벤치마크 ↓ + 환각률 ↑(도구 없을 때)
      + 도구 연결 시 검증 가능한 답변 구조
```

## 핵심
AIME·코드 벤치마크에서 파라미터당 성능이 급등하는 반면, SimpleQA 같은 사실 회상 벤치마크는 제자리거나 오히려 나빠진다. 저자는 이를 우연이 아니라 **설계 목표**로 읽는다. 사실은 파라미터당 약 2 bit의 고정 비용을 먹고, 훈련 직후부터 부패한다. 반면 추론 절차(분해·추적·검증·백트래킹)는 소수 절차의 반복이라 압축이 잘 되고, distillation으로 소형 모델에 잘 전이된다. 따라서 labs는 부패하는 지식을 weights에서 빼고, 부패하지 않는 절차만 남기는 트레이드를 의도적으로 수행한다는 것이다.

## 깊이
- **[지식 형태 변화]** 살아남는 지식은 "폭넓고 얕은" 형태다. PostgreSQL이 뭔지, MVCC가 대략 뭔지는 알지만 특정 버전의 planner 기능은 모른다. 저자는 이 층위가 질문 이해·검색 대상 판단·출처 신뢰 평가에 필요한 최소 폭이라고 본다. 깊이는 검색이 싸고 저장이 비싸므로 제거 대상이다.
- **[환각 구조 전환]** weights 속 잘못된 사실은 grep도 diff도 못 하고, 고치려면 fine-tune이 필요하다. 외부 문서로 옮기면 잘못된 사실에 "주소"가 생겨 문서를 고치면 즉시 반영된다. 저자는 이를 "평범한 데이터 버그"로 격하된다고 표현한다. 단, 모델이 출처를 오독·오결합하는 환각은 남는다고 스스로 한계를 인정한다.
- **[소비자 GPU 전망]** DeepSeek V4-Flash는 13B active지만 expert 합 284B 대부분이 사실 저장. 저자는 이 지식을 제거하면 20~40B·4-bit 양자화로 24GB GPU에 들어갈 수 있다고 주장한다. (검증 필요·불확실: expert 제거 시 추론 품질 유지 여부는 원문에 근거 없음.)

## 용어 풀이
- **harness** — 모델이 모르는 지식을 runtime에 공급하는 외부 장비(검색·도구·문서). 비유: CPU에 프로그램을 올리듯 모델에 세계 상태를 올려주는 랙. 비유가 깨지는 지점: CPU와 달리 검색 결과 품질·노이즈가 답변에 직접 영향을 주므로 "올리기만 하면 됨"이 아니다.
- **distillation** — 큰 모델의 풀이 패턴을 작은 모델에 학습시키는 것. 비유: 숙련자 풀이 노트로 신입을 교육. 깨지는 지점: 노트에 없는 예외·맥락은 전이되지 않는다.
- **active parameters** — MoE에서 토큰당 실제로 연산되는 파라미터 수. 총 파라미터와 다름.

## 시각 자료
| 구분 | weights 내 사실 | 외부 harness 사실 |
|---|---|---|
| 부패 주기 | 훈련 직후 시작 | 문서 갱신 시 즉시 반영 |
| 오류 수정 | fine-tune(고비용·부작용) | 문서 편집(저비용) |
| 검증 가능성 | 불가 | 출처 확인 가능 |
| 비용 구조 | 모든 forward pass 고정 | 필요 시 on-demand lookup |

## 핵심 시사점 / 판단
- (저자 주장) 지식-추론 분리는 "설계 목표"이며, 모델 카드에서 knowledge cutoff가 사라지는 미래가 온다.
- (저자 주장) 이 구조가 환각을 "거의" 해결한다. 단, 출처 오독 환각은 남는다고 인정.
- (검증 필요·불확실) "2 bit/param" 수치는 Physics of Language Models 시리즈 인용이나, 원문이 직접 측정한 것은 아님.
- (검증 필요·불확실) expert 제거 후 추론 품질 유지, 소비자 GPU 전망은 구체적 근거 없음.

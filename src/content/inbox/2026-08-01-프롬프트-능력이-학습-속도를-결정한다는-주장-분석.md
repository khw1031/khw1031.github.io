## TL;DR
- (저자 주장) AI 시대에 학습 속도는 재능이 아닌 '질문의 질(프롬프트)'로 결정된다 — 마케팅 글이며 객관적 근거는 제시되지 않음.

## 큰 그림
```
[저자 주장 구조]

   재능(A)                    질문/프롬프트(B)
      │                             │
      ▼                             ▼
  ┌─────────┐                ┌──────────────┐
  │ 20시간  │                │   20시간     │
  │ (과거?) │                │ → 분야 완주  │
  └─────────┘                └──────────────┘
                                     │
                              프롬프트 300개
                              《다크심리학2》
                              (상업적 유도)
```

## 핵심
- 저자는 "배움의 속도 = 재능 × 시간"이라는 기존 공식을 "배움의 속도 = 질문의 질(프롬프트)"로 치환한다. AI 도구가 보편화되면서 **무엇을 아느냐**보다 **무엇을 어떻게 묻느냐**가 차별점이 된다는 논리다. 이 주장은 "같은 AI를 써도"라는 전제에서 출발하므로, 도구 접근성은 동일하고 숙련도만 다르다는 조건이 깔려 있다.

## 깊이
- **[주장-비교 수치]** "프롬프트를 아는 사람은 20시간, 모르는 사람은 1년"이라는 대비는 핵심적 주장이지만, 어떤 분야·어떤 도구·어떤 수준의 '완주'를 기준으로 하는지 **원문에 없음**. 구체적 실험·설문·출처 없이 제시된 수치이므로 마케팅용 과장으로 볼 여지가 크다.
- **[주장-상업 구조]** 이 게시물은 《다크심리학2》 도서 판매를 위한 퍼널(funnel) 콘텐츠다. "유료급 실전 프롬프트 300개"라는 보상을 미끼로 구매를 유도하는 전형적 소셜 커머스 구조를 띤다. 따라서 주장 자체가 책 판매를 위한 설득 장치일 가능성이 높다.
- **[원문에 없음]** 프롬프트 6개 '맛보기'가 언급되지만, 본 입력에는 해당 프롬프트 내용이나 방법론이 포함되어 있지 않다.

## 용어 풀이
- **프롬프트(Prompt)** — AI에게 던지는 질문·지시문 / 비유: "레스토랑에서 주문하는 방식" / 비유가 깨지는 지점: 프롬프트는 반복 수정(iteration)이 가능하지만, 주문은 일회성이다.
- **다크심리학** — 원문 맥락상 AI 프롬프트 기법을 심리학 프레임으로 패키징한 브랜드명 / 원문에 정의 없음.

```
│  상업성       │  《다크심리학2》 구매 유도      │ → 명확한 CTA 존재
└──────────────┴───────────────────────────────┘
```

## 핵심 시사점 / 판단
- **(저자 주장)** 프롬프트 역량이 AI 시대의 새로운 리터러시이며, 이를 체계화한 자료가 학습 효율을 높인다.
- **(검증 필요·불확실)** "20시간 vs 1년" 수치에 대한 실험적 근거가 없다. 프롬프트 숙련도와 학습 성과 간 상관관계는 LLM 연구 분야에서 탐구되고 있으나(예: prompt engineering 효과성 연구), 본 게시물은 이를 인용하지 않는다.
- **(판단)** 이 글은 교육 콘텐츠가 아니라 **마케팅 카피**로 읽어야 한다. 주장의 타당성과 별개로 상업적 의도가 구조에 내장되어 있다.

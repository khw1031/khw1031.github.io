## TL;DR
- 동일 프롬프트로 Claude·ChatGPT·Figma Make 세 도구의 UI 생성 결과를 비교한다고 하나, **실제 결과물·프롬프트·평가 기준이 본문에 없어 검증 불가**한 인스타그램 홍보 포스트다.

## 큰 그림
```
[인스타 포스트 @tegadesigns1]
│
├─ 주장: "Same prompt → 3개 도구 비교"
│   ├─ Claude        ─┐
│   ├─ ChatGPT       ─┼─ 이미지/영상에 결과 있을 것으로 추정
│   └─ Figma Make    ─┘   (텍스트만으론 확인 불가)
│
├─ CTA: 댓글 "Prompt" → 프롬프트 공유
│
└─ 해시태그: #uiuxdesigner #figma #websitedesigner
     └─ 타깃: UI/UX 디자인 입문·관심층
```

## 핵심
게시물은 "같은 프롬프트를 세 AI 도구에 넣으면 어떤 UI가 나오는지"를 보여주며 독자 투표를 유도하는 **참여형 숏폼 콘텐츠**다. 그러나 본문 텍스트에는 프롬프트 전문, 각 도구의 출력 스크린샷 설명, 평가 기준이 **하나도 포함되지 않는다**. 비교의 실체는 첨부 이미지·영상에 있을 것으로 추정되나, 텍스트 입력만으로는 이를 확인할 수 없다. "댓글로 Prompt를 받으라"는 구조는 콘텐츠 자체보다 **팔로워 참여·알고리즘 부스팅**을 목적으로 하는 전형적 인스타그램 성장 전략이다.

## 깊이
- **[비교 구조 부재]** "Same prompt"라 했지만 프롬프트 내용, 출력 해상도, 반복 횟수, 평가 축(레이아웃·색상·반응형 등)이 원문에 없음. 따라서 "Pick your winner"는 근거 없는 인상 투표에 그친다.
- **[도구 포지셔닝]** Claude·ChatGPT는 범용 LLM 기반 코드/디자인 생성, Figma Make는 디자인 도구 내장 AI로 카테고리가 다르다. 동일 프롬프트 비교가 성립하려면 출력 형식(코드 vs 디자인 파일)을 맞춰야 하는데, 이에 대한 설명이 **원문에 없음**.
- **[CTA 구조]** "comment Prompt"는 DM 자동화(ManyChat 등)로 프롬프트를 배포하는 흔한 퍼널. 콘텐츠 가치보다 **리스트 빌딩·재방문 유도**가 주목적일 가능성이 높다(저자 의도이므로 **불확실**).

## 용어 풀이
- **Figma Make** — Figma 안에 내장된 AI 디자인 생성 기능. 비유: "요리 앱 안에서 '이런 요리 만들어줘'라고 말하면 플레이팅까지 나오는 기능." 다만 아직 출력 품질·제어 범위가 제한적이라 '완성된 디자인 시안'이라기엔 이르다.
- **Same prompt 비교** — 동일 입력으로 모델 출력을 나란히 놓는 벤치마크. 비유: "같은 악보를 세 연주자에게 주고 누가 잘 치나 듣기." 그러나 UI 생성은 악보와 달리 해석 자유도가 극히 커서, **출력 형식·후처리·반복 횟수를 통제하지 않으면 공정한 비교가 성립하지 않는다**는 점에서 비유가 깨진다.

## 시각 자료
| 항목 | 본문 포함 여부 | 비고 |
|---|---|---|
| 사용 프롬프트 전문 | ✗ | 댓글 CTA로 유도 |
| 각 도구 출력 이미지 설명 | ✗ | 첨부 미디어 추정 |
| 평가 기준·점수 | ✗ | 원문에 없음 |
| 도구 버전·설정 | ✗ | 원문에 없음 |

## 핵심 시사점 / 판단
- (저자 주장) "Same prompt로 세 도구를 비교하면 승자를 고를 수 있다." → **검증 필요**. 프롬프트·출력·기준이 공개되지 않아 주장의 근거를 확인할 수 없다.
- (검증 필요·불확실) Figma Make와 범용 LLM을 동일 선상에서 비교하는 것이 метод론적으로 타당한지 원문에서 설명 없음.
- (사실) 게시물은 참여 유도 CTA + 해시태그 기반 노출 구조를 사용한다.

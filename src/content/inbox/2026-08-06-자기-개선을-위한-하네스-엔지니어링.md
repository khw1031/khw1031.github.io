## TL;DR
- 근미래 AI 자기 개선의 핵심은 모델 가중치가 아니라 **하네스(실행 환경·도구·맥락·평가)**를 스스로 고치는 메타 루프이며, 평가기 신뢰성과 인간 감독이 병목이다.

## 큰 그림
```
                 [재귀적 자기 개선(RSI)]
                          │
         ┌────────────────┼────────────────┐
         ▼                ▼                ▼
   가중치 갱신      하네스 엔지니어링   훈련 파이프라인
   (장기·불확실)    (단기·현실 경로)    (간접 증류 등)
                          │
      ┌───────────┬───────┴────────┬────────────┐
      ▼           ▼                ▼            ▼
  맥락관리     워크플로         하네스 코드   평가/권한
  ACE/MCE      ADAS/AFlow      Meta-Harness   루프 외부
                              Self-Harness     (인간 감독)
                              AHE / DGM
```

## 핵심
- I. J. Good(1965)과 Yudkowsky(2008)이 제시한 RSI는 원래 "AI가 자신의 인지 장치를 개선하는 피드백 루프"였으나, 현대 AI에서는 가중치 재작성보다 **배포 계층(하네스)을 개선해 더 나은 후속 결과를 얻는 방식**으로 구체화되었다(저자 주장).
- 하네스는 단순 프롬프트가 아니라 **워크플로·파일 기반 영속 메모리·서브에이전트·권한·평가·상태 관리**를 묶은 런타임 시스템이다. Claude Code, Codex, Cursor 등이 공유하는 도구 인터페이스(파일·셸·git·MCP·spawn_agent 등)가 그 실체다.
- 최적화 대상은 `지시 프롬프트 → 구조화된 맥락 → 워크플로 → 하네스 코드 → 최적화기 코드`로 순차적으로 확장되며, 각 단계는 이전 단계를 포함하면서 더 큰 설계 공간을 연다.
- 하네스 성숙도와 모델 지능은 **공진화**한다. 약한 모델은 하네스 편집은 가능해도 활용(harness-benefit)에서 이득을 얻지 못하며, 중간급 모델이 가장 큰 개선 폭을 보인다(Lin et al. 주장).

## 깊이
- **[하네스 전체 최적화 — Self-Harness / AHE]** 맥락이나 워크플로 조각이 아니라 하네스 전체를 수정 대상으로 삼는다. Self-Harness는 ①약점 채굴(verifier 기반 실패 군집화) → ②하네스 제안(보존할 성공 행동 + 편집 가능 영역) → ③검증(held-in/held-out 이중 통과 시에만 병합) 루프로 Terminal-Bench-2 모델별 맞춤 개선을 보였다. AHE는 **관찰 가능성 3종**(구성 요소·경험·결정)을 도입해 "어떤 실패가 어떤 파일의 어떤 줄 때문에 생겼는지"까지 추적하고, verifier·LLM 설정을 읽기 전용으로 고정해 보상 해킹을 차단한다. AHE가 벤치마크 튜닝이 아닌 **엔지니어링 경험의 인코딩**임을 보여준 증거는, 고정 하네스가 SWE-bench Verified로 전이되었다는 점이다(저자 주장).
- **[진화적 탐색 — DGM]** Darwin Gödel Machine은 하네스 저장소 자체를 진화시키는 방식으로, 고정 Claude 3.5 Sonnet 기반 에이전트의 SWE-bench Verified 성능을 **20% → 50%**, Polyglot을 14.2% → 30.7%로 끌어올렸다. 다만 평가가 빠르고 객관적인 영역(행렬곱, GPU 커널, 알고리즘 대회)에 적합하며, 평가가 느리거나 모호한 영역에서는 확장이 어렵다(저자 주장).
- **[자동 연구의 실패 패턴]** Trehan & Chopra의 개방형 실험에서 논문까지 완주한 경우는 4개 중 1개에 그쳤고, ①훈련 데이터 기본값 편향 ②실행 압박에 따른 구현 이탈 ③메모리 저하 ④과도한 낙관(p-hacking) ⑤도메인 지능 부족 ⑥약한 과학적 안목의 6가지 실패 유형이 반복되었다.

## 용어 풀이
- **하네스(harness)** — 모델을 감싸는 실행·조율 시스템. 비유: "자동차의 운전석+계기판+변속기". 모델은 엔진이지만 핸들·브레이크·네비가 하네스. 깨지는 지점: 자동차와 달리 하네스는 자기 코드를 고칠 수 있다.
- **재귀적 자기 개선(RSI)** — AI가 자신의 개선 장치를 다시 개선하는 루프. 비유: "자기 설명서를 고쳐가며 더 빨리 배우는 학생". 깨지는 지점: 학생과 달리 보상 해킹·장기 기억 붕괴 같은 구조적 실패가 발생한다.
- **보상 해킹** — 목표 지표만 맞추려 본질을 우회하는 행동. 비유: "시험 문제만 외우는 학생". 깨지는 지점: LLM은 의도적 속임수가 아니라 확률적 패턴 학습 결과로 해킹한다.
- **진화적 탐색** — 후보 집단을 변이·선택하며 기울기 없이 최적화. 비유: "자연선택". 깨지는 지점: 생물과 달리 적합도 함수가 취약하면 집단이 잘못된 방향으로 수렴한다.

## 핵심 시사점 / 판단
- **(저자 주장)** 단기 RSI의 실용 경로는 가중치가 아닌 하네스이며, 하네스 코드가 최적화 언어로 부상한다.
- **(저자 주장)** AHE의 벤치마크 전이 결과는 하네스 개선이 "경험의 인코딩"임을 시사한다.
- **(검증 필요·불확실)** SIA의 하네스-가중치 공동 최적화는 작업 에이전트가 약해 결론이 잠정적. Goodhart 효과 미해결.
- **(검증 필요·불확실)** DGM의 20% → 50% 수치는 Claude 3.5 Sonnet 단일 고정 기준이며, 최신 모델에서의 재현 여부는 원문에 없음.

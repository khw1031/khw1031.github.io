## TL;DR
- xAI가 공개한 '그록 봇'은 봇마다 독립 가상 컴퓨터(브라우저·저장소·터미널)를 할당하여, API가 아닌 **직접 로그인 방식**으로 외부 서비스를 조작하는 자율 에이전트다(원문 주장, 기술적 세부 구조는 원문에 없음).

## 핵심
- 원문에 따르면 그록 봇의 차별점은 **API 의존 탈피**다. 기존 자동화(RPA·Zapier 등)는 서비스가 공개한 API 엔드포인트가 있어야 연동할 수 있었는데, 그록 봇은 인간처럼 브라우저에 로그인하여 UI를 직접 조작하므로 **API가 없는 서비스도 처리 대상**이 된다.
- 이를 가능하게 하는 구조적 전제는 **봇 1개 = 가상 컴퓨터 1대**라는 할당 모델이다. 각 봇이 자신만의 브라우저 세션·파일 시스템·셸을 가지므로, 여러 봇이 동시에 서로 다른 서비스에 로그인한 상태를 유지할 수 있다고 원문은 설명한다.
- 원문은 "애착 에이전트"라는 표현을 사용하는데, 정확한 기술적 정의는 원문에 제시되지 않았다(불확실). 맥락상 사용자 개인에 맞춤화된 상주형 에이전트를 지칭하는 홍보적 표현으로 추정된다.

## 깊이
- **[가상 컴퓨터 할당 모델]** 일반적인 LLM 에이전트(Function Calling 기반)는 API 호출만 가능하지만, 그록 봇은 OS 수준의 격리 환경을 제공한다고 주장한다. 이는 **Computer Use**(Anthropic)나 **Operator**(OpenAI) 계열의 '브라우저 조작 에이전트'와 같은 범주에 속한다. 다만 원문에는 컨테이너인지 VM인지, 리소스 상한이 어느 정도인지에 대한 정보가 없다(원문에 없음).
- **[API 없는 업무 처리]** "메일·노션·슬랙에 직접 로그인"이라는 원문 진술은, 서비스가 API를 폐쇄하거나 rate limit을 강하게 걸어도 웹 UI가 열려 있으면 자동화가 가능하다는 의미다. 반대로 이는 **서비스 약관 위반**(자동 로그인·스크래핑 금지 조항) 가능성을 내포한다(원문에 언급 없음).
- **[7일 무료·자동 갱신 없음]** 원문은 비용 장벽을 낮춘 체험 전략을 강조한다. 유료 전환 시 가격·봇 수 제한·실행 시간 상한 등은 원문에 없다.

## 용어 풀이
- **에이전트(Agent)** — 스스로 판단해 도구(API·브라우저)를 사용하는 AI 프로그램 / 비유: 심부름꾼 / 비유가 깨지는 지점: 심부름꾼은 지시를 거부할 수 있지만, 에이전트의 '자율성'은 설계자가 정한 범위 내로 제한된다.
- **가상 컴퓨터** — 실제 하드웨어 없이 소프트웨어로 구현된 PC 환경 / 비유: 호텔 방(필요할 때 배정받고 반환) / 비유가 깨지는 지점: 호텔 방은 공유 인프라지만, 원문이 말하는 격리 수준(컨테이너 vs VM)은 불확실.
- **애착 에이전트** — 원문에서 사용한 표현. 사용자에 밀착된 개인 비서형 에이전트를 의미하는 것으로 보이나, 기술 표준 용어가 아니며 정확한 정의는 원문에 없다(불확실).

## 시각 자료
| 비교 항목 | 기존 API 기반 에이전트 | 그록 봇(원문 주장) |
|---|---|---|
| 연동 방식 | REST API 호출 | 브라우저 로그인 + UI 조작 |
| 서비스 호환 | API 공개된 서비스만 | 웹 UI 있는 서비스 전반 |
| 격리 모델 | 프로세스/스레드 | 가상 컴퓨터(세부 불확실) |
| 약관 리스크 | 일반적으로 낮음 | 자동화 금지 조항과 충돌 가능 |
| 안정성 | API 스펙 기반(구조적) | UI 변경 시 깨질 수 있음(취약) |

## 핵심 시사점 / 판단
- **(저자 주장)** API가 열리지 않은 업무까지 자동화할 수 있어 업무 범위가 크게 확장된다.
- **(검증 필요·불확실)** "애착 에이전트"라는 용어의 기술적 정의, 가상 컴퓨터의 구체적 격리 방식, 보안·인증 정보 저장 방식, 동시 실행 봇 수 상한, 가격 체계는 원문에 없다.
- **(검증 필요·불확실)** 웹 UI 조작 기반 에이전트는 UI 변경에 취약하며, 서비스 약관 위반 리스크가 있을 수 있다(원문 미언급).
- **(불확실)** "일론 머스크가 공개한"이라는 표현이 xAI의 공식 발표인지, 마케팅 파트너의 재해석인지 원문만으로는 구분 불가.

## TL;DR
- OpenAI가 Codex(코덱스) 기반 게임 개발 해커톤을 전 세계 최초로 서울에서 개최하며, 8월 26일까지 신청 가능하다.

## 큰 그림
```
OpenAI 게임 빌더스 해커톤 (서울)
├── Track 1 — 코덱스로 만든 게임 쇼케이스
│   └── 수상: 총 $50,000 크레딧 + ChatGPT Pro 1년
├── Track 2 — 5시간 라이브 빌드 챌린지
│   └── 상위 3팀: ChatGPT Pro 1년
├── 공통 혜택: 본선 참가자 전원 $100 API 크레딧
├── 특별 세션: 송재경 개발자 강연 (바람의나라·리니지)
└── 조건: 팀당 최대 3명 / 브라우저 플레이 가능 / 기존 프로젝트 OK / 40팀 본선
```

## 핵심
- OpenAI가 게임 개발자를 위한 해커톤을 **서울에서 전 세계 최초로** 공식 개최한다고 발표했다(원문 기준, 1차 출처 @openai 인용).
- 핵심 도구는 **Codex**(코덱스)로, AI 에이전트가 코드를 작성하는 '바이브 코딩' 방식으로 게임을 만들고 실제 출시까지 이어지는 흐름을 체험하는 자리다.
- 두 트랙으로 나뉜다. Track 1은 사전에 만든 게임을 선보이는 **쇼케이스**형이고, Track 2는 현장에서 5시간 안에 게임을 만드는 **라이브 빌드** 챌린지다.
- 비개발자도 참가 가능하다고 원문은 밝히고 있으며, 기존 프로젝트도 제출할 수 있어 진입 장벽을 낮춘 구조다.

## 깊이
- **[Codex란]** OpenAI의 코딩 에이전트 도구로, 자연어 지시를 받아 코드를 자동 생성·수정한다. '바이브 코딩'은 개발자가 세부 구현보다 의도·방향을 제시하고 AI가 코드를 완성하는 작업 방식을 일컫는 신조어다.
- **[혜택 구조]** 본선 40팀 전원에게 $100 API 크레딧을 주고, Track 1 수상팀에는 총 $50,000 크레딧과 ChatGPT Pro 1년을 제공한다. Track 2는 상위 3팀에 Pro 1년. 현금 상금이 아닌 **API 크레딧**이라는 점이 특징인데, 이는 수상 후에도 OpenAI 생태계 내에서 계속 개발하도록 유도하는 설계로 읽힌다(저자 해석, 검증 필요).
- **[송재경 개발자 세션]** '바람의나라', '리니지'를 만든 송재경 개발자가 Codex로 게임 개발에 복귀한 경험을 공유한다. 원문은 이를 "코덱스로 게임 개발에 복귀하게 된 이야기"라고만 언급하고 있어 구체적인 복귀 프로젝트명은 **원문에 없음**.

## 용어 풀이
- **Codex(코덱스)** — OpenAI의 AI 코딩 에이전트 / 비유: "개발자 옆자리에서 코드를 대신 써주는 인턴" / 비유가 깨지는 지점: 인턴과 달리 맥락 이해에 한계가 있고, 복잡한 아키텍처 판단은 여전히 사람이 해야 함.
- **바이브 코딩(Vibe Coding)** — AI에게 의도를 전달해 코드를 생성하는 작업 방식 / 비유: "요리 재료를 말하면 AI가 요리해 주는 것" / 비유가 깨지는 지점: 결과물 품질 보장이 안 되고, 디버깅 시 원인을 찾기 어려울 수 있음.
- **API 크레딧** — OpenAI API 호출에 사용할 수 있는 선불 잔액 / 비유: "특정 가게에서만 쓸 수 있는 상품권" / 비유가 깨지는 지점: 현금 환급 불가하며 유효기간·사용 조건이 있을 수 있음(원문에 세부 조건 없음).

## 핵심 시사점 / 판단
- **(저자 주장)** 비개발자도 참가 가능하며, 바이브 코딩으로 게임을 만들 수 있는 새로운 개발 방식의 장이 열린다.
- **(검증 필요·불확실)** "전 세계 최초 서울 개최"라는 표현이 원문에 있으나, OpenAI 공식 발표에서 이 표현이 어떻게 정확히 사용되었는지는 1차 출처(@openai) 직접 확인 필요.
- **(불확실)** $50,000 크레딧이 팀당인지 Track 전체 풀인지, 크레딧 유효기간은 얼마인지 등은 **원문에 없음**.
- **(검증 필요)** 2025년 기준 연도 명시 없이 "8월 4일~26일"로만 기재되어 있어, 실제 행사 연도는 1차 출처 확인이 필요하다.

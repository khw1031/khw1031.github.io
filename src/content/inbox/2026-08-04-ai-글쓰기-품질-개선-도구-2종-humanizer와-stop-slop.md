## TL;DR
- AI 글쓰기의 흔적을 없애는 두 가지 접근법 — **패턴 제거(Humanizer)** 와 **다축 채점(stop-slop)** — 을 조합하면 출력 품질이 크게 개선된다는 주장이나, 효과는 프롬프트 공학 수준이며 체계적 검증은 없다.

## 큰 그림
```
AI 생성 텍스트 문제
│
├─ 증상: 과장된 중요성, 브로셔 톤, 빈 약동사, 과도한 대시, 동질화된 문체
│
├─ 해결 접근 A ── Humanizer (31k stars)
│   └─ Wikipedia "Signs of AI writing" 기반 금지 패턴 필터
│       └─ 사용자 문단 2개를 붙여넣으면 목소리 교정
│
├─ 해결 접근 B ── stop-slop (14k stars)
│   └─ 5축 채점 (방향/리듬/자신감/진정성/밀도) × 10점 = 50점 만점
│       └─ 35점 미만 → 자동 재작성 루프
│
└─ 한계
    ├─ 모든 AI가 같은 필터 쓰면 다시 동질화 (댓글 지적)
    └─ 체계적 벤치마크 부재 (저자 주장 수준)
```

## 핵심
- 저자(@adrknapp)는 AI가 생성한 텍스트를 개선하는 두 가지 "skill"(프롬프트 모듈)을 소개하며, 이를 적용 전후로 글의 질이 크게 달라졌다고 **주장**한다. 첫 번째 도구 Humanizer는 Wikipedia의 "Signs of AI writing" 문서를 기반으로 AI 글쓰기의 전형적 징후 — 과장, 브로셔 톤, 의미 없는 약동사, 불필요한 대시 — 를 명시적으로 금지하는 필터를 구성한다. 여기에 사용자 본인의 문단 두 개를 제공하면 그 목소리에 맞춰 출력을 교정하는 기능까지 포함한다. 두 번째 도구 stop-slop은 교정 대신 **채점** 방식을 취한다. 방향성, 리듬, 자신감, 진정성, 밀도라는 다섯 축으로 1~10점을 매겨 총 50점 중 35점 미만이면 재작성을 요구한다. 두 도구의 철학 차이는 명확하다. Humanizer는 "하지 말 것"을 지정하는 소거법이고, stop-slop은 "얼마나 잘했는지"를 수치화하는 평가법이다. 이 둘을 함께 사용하면 소거법이 놓친 품질 문제를 평가법이 잡아내는 상호보완 구조가 된다.

## 깊이
- **[Humanizer — 기반 자료]** Wikipedia "Signs of AI writing" 페이지는 실제 AI 텍스트를 교정해 온 편집자들의 경험에서 추출된 패턴 모음이다(2차 자료). 이를 프롬프트로 변환한 것이 Humanizer의 핵심이다.
- **[stop-slop — 채점 메커니즘]** "35/50 미만 시 재작성"이라는 역치 기반 루프는 저자 **주장**에 따르면 단순히 "写得不好(잘못 썼다)"고 피드백하는 것보다 구체적 개선 방향을 제공한다고 한다. 리플(2/10)에서도 이 채점 방식이 긍정적으로 언급되었다.
- **[동질화 역설]** 댓글(6/10)은 핵심적 문제를 제기한다: 모든 AI가 같은 "탈套路" 필터를 쓰면 결과물이 다시 균일해질 수 있다는 점. 이는 "anti-AI 필터" 자체가 새로운 패턴이 되는 자기 참조적 한계다.
- **[나머지 트윗]** 7~10/10은 별도 주제(AGENTS.md, DevTools 기반 API/MCP 서버 제작 팁, pdf-inspector WASM 엔진, CLAUDE.md 설정)로, 본문 주제와 직접 무관하여 생략한다. 원본 스레드 확인 권장.

## 용어 풀이
- **skill (여기서)** — LLM에 주입하는 프롬프트 모듈 / 비유: 레시피 카드 / 깨지는 지점: 코드 실행 로직이 포함된 실제 소프트웨어 skill과 혼동 가능.
- **약동사(gerúndio vazio)** —葡萄牙語로 "빈 약동사". 진행형 형태의 의미 없는 표현 / 비유: "하고 있는 중입니다"처럼 행동 없이 움직이는 말 / 깨지는 지점: 언어마다 해당 문법 범주가 다름.

## 시각 자료
| 도구 | Stars | 접근법 | 입력 | 출력 기준 |
|------|-------|--------|------|-----------|
| Humanizer | ~31k | 금지 패턴 필터 (소거) | Wikipedia 패턴 + 사용자 문단 2개 | 패턴 제거 + 목소리 교정 |
| stop-slop | ~14k | 5축 채점 (평가) | 생성된 텍스트 | 35/50 이상 or 재작성 |

## 핵심 시사점 / 판단
- **(저자 주장)** 두 도구를 조합하면 AI 텍스트 품질이 "물에서 포도주로" 바뀔 만큼 개선된다.
- **(저자 주장)** stop-slop의 수치 채점이 모호한 불만 피드백보다 효과적이다.
- **(검증 필요·불확실)** Star 수가 프롬프트 효과의 증거는 아님. 통제 실험 없이 체감 기반 평가.
- **(검증 필요·불확실)** 동질화 역설 — 보편적 필터 적용 시 새로운 패턴 고착 가능성.

## TL;DR
- 전문가가 된 뒤 쓰지 말고, **아직 모르기 때문에** 써라. 글쓰기가 조사·검증·피드백을 강제하는 학습 장치가 된다.

## 큰 그림
```
[아직 모르는 주제 선택]
        │
        ▼
[반론 가능한 하나의 주장 세우기] ← 제약이 탐색 범위를 좁힘
        │
        ▼
[쓰면서 조사 → 막히는 지점 발견] ← "이게 맞나?" 빈틈 노출
        │
        ├─ 생각이 바뀌면 ✓ 좋은 신호
        ├─ 결론이 서론보다 명확해지면 ✓ 학습 발생
        │
        ▼
[피드백 획득]
  ├─ 공개: 독자 반응 (두꺼운 피부 필요)
  └─ 비공개: LLM에 "review, please:" + 본문
        │
        ▼
[다음 주제로 이동 — 배울 것이 남아 있으면 반복]
```

## 핵심
저자(Sean Goedecke)는 "글쓰기 = 학습 검증 장치"라고 주장한다. 머릿속에서는 이해한 것처럼 느껴지지만, 문장으로 압축하면 "잠깐, 이게 사실인가?"라는 빈틈이 반드시 드러난다. 이 빈틈이 조사를 강제하고, 조사 과정에서 최초 생각과 다른 결론에 도달한다. 저자는 이를 우연이 아닌 **설계된 구조**로 만든다. 무난한 생각 나열 대신 "합리적인 사람이 반대할 수 있는 주장"을 하나 세우면, 반론에 답하기 위해 자연스럽게 더 파게 된다. 시 쓰기의 운율 제약처럼, 이 논쟁 가능성이라는 제약이 오히려 "다음에 무엇을 쓸지"를 좁혀 지속적 글쓰기를 쉽게 만든다.

## 깊이
- **[주장 세우기 → 조사 강제]**: 저자는 "나도 동의한다" 수준의 글, 아무도 반대하지 않을 초안을 버린다. 예: o3 GeoGuessr 글은 "AI 프롬프트가 작동 안 한다"에서 시작해 최신 모델이 o3 위치추론 능력을 상실했다는 발견으로 확장. C2PA 글은 PKI·개인 키 관리까지 조사가 깊어짐. 시작점과 도착점이 달라지는 것이 정상.
- **[비전문가의 글쓰기 정당화 3가지]**: ①초보자가 "왜 이 문제가 존재하는가"부터 설명할 수 있음(전문가는 당연시함). ②약간의 조사로 대중 통념이 틀렸음을 발견 가능(예: "LLM 프롬프트 1회=물 500ml" 수치 반박, Apple 'Illusion of Thinking' 논문이 추론이 아닌 지속성을 측정한다는 분석). ③실명·이력을 공개해 전문가인 척하지 않으면 됨.
- **[LLM 피드백 실용 팁]**: 정교한 리뷰 프롬프트보다 `"review, please:"` + 본문 붙여넣기가 효과 면에서 큰 차이 없었음. 다만 OpenAI 모델은 주장을 약화·유보 표현 추가 방향으로 끌고 가는 경향 주의. 기술적 오류 검출에는 유용.

## 용어 풀이
- **C2PA** — 콘텐츠 출처 인증 표준 / "사진에 디지털 도장 찍기" / 비유 한계: 도장 자체는 위조 가능 여부까지 보증하지 못함.
- **PKI (Public Key Infrastructure)** — 공개키 기반 인증 체계 / "전 세계가 믿는 공증소 네트워크" / 비유 한계: 신뢰 루트 자체의 정치적 문제는 설명 못 함.
- **Steering vectors** — LLM 내부 표현 방향을 조작하는 벡터 / "모델 사고의 핸들을 돌리는 것" / 비유 한계: 실제 메커니즘은 선형 회전이 아닐 수 있음.

## 시각 자료
| 학습 확인 기준 | 긍정 신호 | 부정 신호 (초안 폐기 고려) |
|---|---|---|
| 집필 중 생각 변화 | 결론이 시작과 다름 | 처음 생각 그대로 |
| 결론 vs 서론 품질 | 결론이 더 명확·구체적 | 서론이 더 나음 |

## 핵심 시사점 / 판단
- (저자 주장) "느끼는 대로 쓰라"는 일반 조언보다 논쟁 가능한 주장 제약이 지속적 글쓰기에 효과적.
- (저자 주장) 비공개 글쓰기 + LLM 피드백만으로도 학습 효과 획득 가능.
- (검증 필요·불확실) "LLM 프롬프트 1회=물 500ml" 반박 등 구체 수치는 원문 요약일 뿐, 1차 데이터 확인 필요.
- (검증 필요·불확실) Apple 'Illusion of Thinking' 논문 해석은 저자 관점이며, 원 논문 저자 입장과 다를 수 있음.

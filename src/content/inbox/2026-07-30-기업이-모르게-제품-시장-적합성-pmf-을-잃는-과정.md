## TL;DR
- 기존 고객이 만족해도 **신규 고객을 반복 확보하는 구조**가 약해지면 ==PMF는 매출 지표보다 먼저, 그러나 조용히 침식된다.==

## 큰 그림
```
                    [PMF(제품-시장 적합성)]
                   /        |         \
      [제품 가치 적합성]  [고객 정의]  [유통 엔진]
            │              │            │
      기존 고객 만족   ICP 표류 ──> 제품 신호 분산
            │              │            │
            └──> 매출엔 늦게 → 영업주기↑/전환율↓ 먼저
                            │
                    리더십 "실행 문제" 오인
                            │
              ┌─────────────┴─────────────┐
        [의도치 않은 표류]          [구조적 변화]
            │                            │
      ICP/JTBD로 재좁힘         다음 고객·시장 명시 선택
```

## 핵심
PMF는 단순히 "좋은 제품"이 아니라 **가치를 만드는 제품 + 비용을 지불하는 고객 + 같은 고객을 반복 확보하는 유통** 세 요소가 동시에 필요하다. 기존 고객이 만족하는 **제품 가치 적합성(Product-Value Fit)** 은 PMF처럼 보이지만 신규 획득까지는 보장하지 않는다. 위치 API 인프라 기업 사례에서처럼 초기 ICP를 대부분 확보하면 신규 획득이 정체되고, 플랫폼이 기본 기능을 내장하면 유효 시장마저 좁아진다. ==제품 가치는 살아있어도 유통 엔진이 없으면 PMF는 이미 빠져나가고 있다.==

이 침식은 세 영역(이하)에 먼저 나타나며, 매출·유지율에 반영되기 전 여러 분기 동안 누적된다.

## 깊이
- **[세 영역-ICP 표류]** 원래 고객군의 성과가 흔들리면 기업은 전략적 합의 없이 고객 범위를 넓힌다. 영업은 비슷한 고객을 계약하고 마케팅은 더 넓은 대상에 메시지를 확장한다. 각 결정은 합리적이지만 누적되면 '누구를 위해 만드는가'가 분산된 ICP로 흐려진다.
- **[세 영역-제품/메시지 표류]** 고객 유형이 다양해지면 기능 요청이 여러 방향에서 들어와 로드맵 기준이 모호해진다(제품 명확성 ↓). 동시에 다양한 요구를 한 가치 제안으로 포괄하기 어려워 메시지가 구체성을 잃고 구매자마다 제품 역할을 조금씩 다르게 전달한다. 계약은 계속 성사되지만 초기만큼 선명하지 않다.
- **[오인 함정]** 침식은 먼저 영업 주기 연장·전환율 저하·이사회 질문에 답하기 어려움으로 나타난다. 리더십은 파이프라인·프로세스·채용으로 '실행 문제'로 대응하지만 근본 원인을 놓친다. ==충성 고객만 판매하면 NPS도 높게 나와 표면 지표가 침식을 가린다.==
- **[진단]** ① 최근 20~25건 vs 9~18개월 전 거래의 구매자/문제/계기 비교 → 시장 중심 이동 확인. ② 제품·영업·마케팅 책임자에게 고객을 각각 설명 → 답이 다르면 공통 인식 분열. ③ 획득 채널 전환율·비용 점검 → 고객 정의/제품 명확성/유통 중 어디가 흔들렸는지 구분.
- **[재조정 사례]** ARR 1,200만 달러 B2B SaaS: 과거 1회 회의 로드맵이 3회까지 이어지고 영업이 새 유형 고객 기능을 요구하기 시작 → PMF 침식 신호로 판단. 구조적 한계로 보고 핵심 조직은 기존 고객 유지·확장, 창업팀은 5,000만 달러 규모 차기 제품·시장 탐색으로 분리. 권한·자원 배분에서 창업자 간 긴장 발생, 성공 여부는 미확인.

## 용어 풀이
- **PMF(제품-시장 적합성)** — 만든 가치, 지불 의향, 반복 획득이 모두 맞물리는 상태. / 비유: 수도꼭지가 물(가치)을 주고, 파이프(유통)가 같은 물을 계속 보내는 상태. / 깨지는 지점: PMF는 정적 상태가 아니라 가격·플랫폼·경쟁 변화에 따라 계속 이동한다.
- **ICP(이상적 고객 프로필)** — 가장 잘 맞는 고객의 구체적 정의. / 비유: 사격 과녁의 중심점. / 깨지는 지점: ICP는 하나의 점이 아니라 유사 특성 묶음이라 '비슷한 고객' 합의 없이 확장하면 경계가 무너진다.
- **JTBD(수행할 작업)** — 고객이 제품을 '고용'해 해결하려는 일. / 비유: 드릴을 사는 건 구멍이 필요해서. / 깨지는 지점: 같은 제품이 고객마다 다른 작업에 쓰일 수 있어 단일 JTBD로 과도하게 좁히면 기회를 놓친다.
- **유통 엔진** — 같은 유형 고객을 규모 있게 반복 획득하는 구조. / 비유: 같은 어종을 매일 잡는 그물. / 깨지는 지점: 유통은 채널 포화·플랫폼 변화에 취약해 과거 효율이 지속된다고 가정하면 안 된다.

## 시각 자료
```
[진단 → 원인 매핑표]
최근 vs 과거 거래가 의미 있게 다르다  → 시장 적합성 중심 이동
조직 3 답변이 크게 다르다             → 공통 고객 정의 분열
채널 전환율↓·획득비용↑                → 유통 엔진 약화
기존 고객은 확장, 신규만 어려움        → ICP 표류 아닐 수 있음(유통)

[대응 분기]
표류 우발적 → ICP/JTBD 재좁힘 (범위 축소=후퇴 아닌 전략)
표류 구조적 → 다음 고객·시장 명시적 선택 (재조정)
합의 안 되면 → 로드맵/GTM/채용이 서로 다른 가정 위에서 진행
```

## 핵심 시사점 / 판단
- (저자 주장) PMF 침식은 매출보다 먼저 영업 주기·전환율·고객 정의 일치도로 나타나며, 리더십이 실행 문제로 오인해 여러 분기를 낭비하기 쉽다.
- (저자 주장) 의도치 않은 표류는 재좁힘으로, 구조적 변화는 명시적 재조정으로 대응해야 하며, 현재 상태에 '이름 붙이는 일'이 선행되어야 한다.
- (검증 필요·불확실) 사례 기업의 재조정(핵심 조직 + 차기 제품 탐색 조직 분리)의 성공 여부는 원문에서 확인되지 않는다.
- (검증 필요·불확실) 순매출 유지율 120%·ARR 1,200만 달러 등 수치은 원문이 제시한 이차자료 수치로, 독립 검증은 불확실하다.

## TL;DR
- 원본 YouTube 영상에서 분석 가능한 텍스트 콘텐츠가 추출되지 않아 리포트를 작성할 수 없다.

## 큰 그림
```
[입력] YouTube URL (m6MWBlkFweQ)
       │
       ▼
[Jina 크롤링] ──► 결과: YouTube 페이지 shell만 반환
       │            (네비게이션, 푸터, 법적 링크만 포함)
       ▼
[분석 대상] ──► 없음 (영상 제목·자막·설명 모두 미추출)
       │
       ▼
[리포트] ──► 작성 불가 (원문에 없음)
```

## 핵심
- Jina가 YouTube 페이지에서 추출한 텍스트는 YouTube 사이트의 **페이지 프레임**(About, Press, Copyright, Terms, Privacy 등)뿐이며, 영상의 실제 내용(제목, 설명, 자막, 트랜스크립트)은 전혀 포함되어 있지 않다. 이는 YouTube가 동적 렌더링(JavaScript 기반 SPA)으로 콘텐츠를 제공하기 때문에 정적 크롤러가 본문에 접근하지 못한 것으로 추정된다(추정, 검증 필요).

## 깊이
- [크롤링 실패 원인 추정] YouTube는 영상 콘텐츠가 클라이언트 사이드에서 JavaScript로 로드되는 구조이므로, 일반적인 HTTP GET 기반 크롤러로는 영상 메타데이터나 자막에 접근하기 어렵다(불확실 — 원문에 크롤링 방법론 명시 없음).
- [대안 경로] YouTube 영상 내용을 분석하려면 다음 경로가 필요할 수 있다: (1) YouTube Data API v3로 영상 description/snippet 조회, (2) 자막 API 또는 외부 자막 추출 도구 활용, (3) 영상 URL의 `- YouTube` 부분이 아닌 실제 제목 확인. 모두 **원문에 없음**.

## 용어 풀이
- **Jina** — 웹 페이지를 LLM 친화적 마크다운으로 변환하는 크롤링 서비스 / 비유: "웹페이지를 번역하는 통역사" / 비유가 깨지는 지점: 동적 렌더링 페이지(YouTube, SPA)에서는 번역 대상 자체를 못 가져올 수 있음.
- **SPA (Single Page Application)** — 페이지 전환 없이 JavaScript로 콘텐츠를 동적 로드하는 웹 앱 / 비유: "한 방 안에서 가구만 바꾸는 집" / 비유가 깨지는 지점: 외부 크롤러는 "방 안"을 보지 못하고 빈 집만 দেখ게 됨.

## TL;DR
- AI 에이전트가 무조건 "더하기"만 하는 문제를, 기존 공학 격언을 자동 호출 스킬로 만들어 "빼기" 반사로 교정하려는 오픈소스 패턴 모음.

## 큰 그림
```
              하나(1)              여럿(N)
           ┌─────────────────┬─────────────────┐
  지금     │   depth/ (19)   │  breadth/ (2)   │
  (now)    │ "이 한 장이     │ "한 진실이      │
           │  깨끗한가?"     │  어디서나        │
           │                 │  일관된가?"      │
           ├─────────────────┼─────────────────┤
  반복     │   coil/ (6)     │   mesh/ (1)     │
  (iter)   │ "매 패스가      │ "여러 시선이    │
           │  다음을          │  진실에          │
           │  가르쳤나?"     │  수렴하는가?"    │
           └─────────────────┴─────────────────┘
  축: 산출물 수(가로) × 시간(세로)
  철학: 모든 스킬은 "추가"가 아닌 "제거·재작성·압축"
```

## 핵심
에이전트에 목표를 주면 파일·옵션·보일러플레이트를 **쌓는다**. 저자는 이를 "진행처럼 보이는 부패"라 진단하고, 해법으로 "모든 스킬이 무언가를 **지운다**"는 역베팅을 제시한다. 이 역베팅은 2×2 매트릭스(산출물 수 × 시간)로 조직되며, 각 칸이 다루는 부패 양상이 다르다. `depth`는 한 산출물의 현재 오염, `breadth`는 여러 산출물 간 사실 분산, `coil`은 반복 주기에서의 학습 손실, `mesh`는 다수 시선의 수렴 검증이다. 설치 후 `/re0`처럼 이름으로 호출하거나 모델이 스스로 발화한다.

## 깊이
- **[depth–re0]** "패치 위에 패치"를 거부하고 산출물을 처음부터 깨끗한 v0로 재작성. Boy Scout Rule(Robert C. Martin, 2008)을 인용하되 "정리"가 아닌 "재작성"으로 한 단계 더 감. 자기 검증: 이미 v0인 문서에 적용 시 한 줄도 바꾸지 않음 → "바꿀 게 없으면 아무것도 안 한다"가 설계 의도.
- **[depth–hate]** 자기 계획에 대한 적대적 검토. "죽일 수 있는 단 하나의 반대 + 가장 싼 실험"만 반환. Egoless programming(Weinberg, 1971)·fail-fast가 뿌리. 사용자 호출 전용이라 의도적 트리거가 필요.
- **[coil–re0-loop + re0-memo + re0-work]** build→QA→교훈 추출→v0 재시작 루프. "코드가 아닌 학습이 축적"되도록, 실패한 빌드는 버리고 교훈만 남김. `catchup`·`nba`가 장기 세션 후 인간의 맥락을 재구성.

## 용어 풀이
- **skill** — 에이전트가 호출 가능한 작은 행동 단위. 비유: "도구함의 드라이버". 한계: 드라이버는 물리적으로 고정됐지만, skill은 프롬프트 해석에 따라 동작이 흔들릴 수 있음.
- **SSOT(Single Source of Truth)** — 한 사실에 하나의 권위 있는 집. 비유: "주민등록 원본". 한계: 원본 자체가 틀리면 모든 포인터가 함께 틀림.
- **readchk** — 지시를 되읽어 진짜 분기점만 질문. 비유: "의사 처방 전 복약 확인". 한계: 분기 판단 자체가 모델 추론이라 오탐 가능.

## 핵심 시사점 / 판단
- (저자 주장) "제약이 제품이다" — 개선할 게 없으면 아무것도 안 하는 절제 자체가 가치.
- (저자 주장) 각 스킬의 [PROOF] 섹션이 자체 도그푸딩 근거이나, 외부 재현·벤치마크는 원문에 없음.
- (검증 필요) `autobahn` 사례에서 "10개 서브에이전트, 0 refusal"은 저자 서술일 뿐 제3자 검증 없음.
- (불확실) "어떤 에이전트에서나" 호환 주장 — 실제 호환 범위·실패 모드 미기재.

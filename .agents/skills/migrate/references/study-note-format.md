# study-note 리프 노트 레이어드 양식

`study-note`의 **리프 개념 노트**를 쓰는 규약이다. 하나의 노트가 입문·중급·전문가 독자를 동시에
감당하되, 층을 나눠 각자 자기 층에서 멈추거나 건너뛰게 한다. 허브(`{category}/index.md`)에는
적용하지 않는다 — 허브는 카테고리 요약 한두 단락 + (자동 렌더되는) 하위 목차면 된다.

## 왜 층을 나누나

한 밀도로 쓴 노트는 반드시 한쪽을 해친다(전문성 역전 효과 — 초보에게 도움이 되는 친절한 안내가
숙련자의 성과를 떨어뜨린다). 그래서 평균 난이도로 뭉개지 말고 **층을 분리하고 위에서 아래로
심화**한다. 입문자는 위에서 멈추고 전문가는 스크롤을 내린다(progressive disclosure).

## 골격

```markdown
---
title: '{대상}의 {다루는 범위} {명사형 장르}'
description: '{선택 — 이 노트가 무엇을 설명하는가 한 줄}'
---

> 한 줄: {스크롤 안 내려도 결론이 잡히는 한 문장}

## 큰 그림
[입문] 부분이 어떻게 맞물리는지. 구조·다관계 개념일 때만 다이어그램을 넣는다(선택).
단일 관계면 ASCII, 여러 관계 종류가 섞이면 mermaid.

## 핵심
[입문→중급] 12살 눈높이 은유로 시작해 메커니즘으로 내려간다. 돌아가는 최소 예시 하나.

## 깊이
[중급→전문가] 소절로 나누고 필수/곁가지를 표식으로 구분한다.

## 용어 풀이
[중급] 번역어(원어) — 한 줄 정의 / 깨짐: 이 개념이 흔들리는 지점

## 확인 질문
[검증] 답을 가린 질문 3개. 하나는 본문에 없던 상황에 적용.

## 근거
[전문가] 실측(저장소 파일 위치)과 외부 출처. 링크는 한 줄 요약 + 1차/2차 + 확인 날짜.

## 관련 개념
앞: {먼저 서야 하는 개념 링크}  /  뒤: {이게 서면 열리는 개념 링크}
```

## 배치 원칙 셋

1. **위에서 아래로 깊어지게.** 입문자는 큰 그림·핵심에서 멈추고, 전문가는 깊이·근거로 내려간다.
   아무도 자기에게 불필요한 층을 강제로 읽지 않게 한다.
2. **층을 표식으로 드러내 건너뛰게 하라.** 소제목("핵심"/"깊이"/"용어 풀이")이 그 표식이다.
   모드를 섞으면 그 순간 그 독자를 놓친다.
3. **용어는 병기, 사례는 격리.** 전문 용어는 번역어(원어)로 정의하고, 실무 사례·예외는 "깊이"
   소절에 모아 입문 독자의 흐름을 끊지 않게 한다.

## 층별로 무엇을 담나

- **입문(큰 그림·핵심)** — 왜 있고 대충 무엇인가. 한 줄 결론 + 문제·동기, 큰 그림, 은유,
  돌아가는 최소 예시. 목표가 없으면 무엇이 중요한지 걸러지지 않는다.
- **중급(깊이·용어 풀이)** — 정확히 무엇이고 왜 그렇게 되나. 정의와 이유를 **분리**하고(정의에서
  멈추지 않는다 — 다음 질문은 이유 쪽에서 나온다), "가깝지만 아닌 것" 하나로 경계를 긋고(한 가지만
  다르고 나머지는 같은 대조쌍), 중간 상태·shape·수치를 구체로 보이고(분포는 수식 말고 그래프로),
  흔한 오해와 왜 그렇게 오해하는지를 적는다. 번역어(원어) 병기는 검색·검증의 진입점이다.
- **전문가(깊이·근거)** — 실무에서 어떻게 쓰고 언제 안 쓰나. 실제 값·설정의 사례, 트레이드오프·
  실패 모드·edge case, 대안과 버려진 길(왜 버려졌나), "없었다면 발명됐을까"(필수 요소 vs 역사적
  관행), 1차 출처.

## 확인 질문 — 필수

레이어를 잘 나눠도 읽기만 하면 남지 않는다. 리프 노트마다 **답을 가린 확인 질문 3개**를 넣고,
그중 하나는 본문에 없던 상황에 적용하게 한다. 답을 다 떠먹이지 말고 스스로 생성할 자리를 둔다.
마이그레이션으로 만든 노트라도 이 장치는 생략하지 않는다.

## 근거 — 실측 우선, 외부는 1차 먼저

출처가 저장소 내부 실측(파일·줄 범위, 실행 결과)이면 그대로 근거로 남긴다. 외부 자료를 걸 때는
공식·1차 출처를 먼저 두고, 링크마다 한 줄 요약과 1차/2차 표시, 확인 날짜를 붙인다. 맨 URL 금지.

## 관련 개념(앞/뒤) — 개념 그래프 엣지

노트를 고립점으로 닫지 않는다. **앞**(먼저 서야 하는 개념)과 **뒤**(이게 서면 열리는 개념)를
링크로 남긴다 — 이것이 개념 그래프의 간선이 된다.

## 안티패턴

| 신호 | 무엇이 무너지나 | 교정 |
| --- | --- | --- |
| 평균 난이도로 뭉갬 | 전문성 역전 — 초보·전문가 둘 다 놓침 | 층 분리 + 위→아래 심화 |
| 시간순 질의응답을 그대로 쌓음 | 같은 개념이 흩어져 다시 안 읽힘 | 개념 단위로 정리 |
| 정의로 끝냄 | 다음 질문이 안 생김 | 정의 뒤에 "왜 그렇게 되는가" |
| 전문 용어를 번역어로만 씀 | 검색·검증 불가, 전문가 층 단절 | 번역어(원어) 병기 |
| 확인 질문 없음 | 읽고 이해된 느낌만 남고 인출 안 됨 | 답 가린 질문 3개 |
| 사례 없이 개념만 | 전문가 층이 비어 판단에 못 씀 | 실무 사례 + 트레이드오프 + 언제 안 쓰나 |
| 관련 개념 링크 없음 | 그래프에서 고립점 | 앞/뒤 링크 |

## 한계

- 이 통합 구조는 **완성된 개념 노트**에만 맞는다. 진행 중 세션의 날것 기록은 별도이며 섞지 않는다.
- 층 경계는 독자의 사전 지식에 따라 움직인다 — 저자가 완벽히 정하지 못한다. 표식으로 건너뛸 여지를
  주는 것이 최선이다.


**규칙:** 같은 입력에서 같은 판정을 재현할 수 있는 규칙은 자연어 지침에만 두지 말고 결정적 lint로 구현해 에이전트의 작업 경계에 연결하라.

## 왜

자연어 규칙은 에이전트가 읽고도 놓치거나 상황마다 다르게 해석할 수 있다. 입력과 판정 기준이 고정되어 있다면 같은 판단을 매번 추론하게 할 이유가 없다. 결정적 lint가 위반 위치와 이유를 직접 반환하게 하면 컨텍스트 사용량을 줄이면서도 누락을 일관되게 막을 수 있다.

다만 주관적 품질 판단까지 억지로 수치화하면 거짓 정밀성과 오탐이 생긴다. 자동화의 대상은 같은 입력과 같은 도구 버전에서 같은 결과를 내고, 통과와 실패의 경계를 명시할 수 있는 규칙으로 제한한다.

## 예시

- (구성한 예) 문서가 목록에 나타나는지를 판정하는 검사기는 실제 목록 생성 코드와 같은 분류 함수를 사용한다. 같은 문서를 입력하면 목록 노출 여부와 숨긴 상위 문서를 항상 같은 상태값으로 반환한다.
- (구성한 예) frontmatter 검사기는 필수 필드와 스키마 위반을 같은 입력에서 동일하게 검출하고, 명백한 오류가 있으면 작업 경계에서 다음 단계로 진행하지 못하게 한다.
- (구성한 예) 규칙 문서 검사기는 저장된 규칙 파일을 전부 열거하고 다음 불변식을 검사한다.
  - 파일은 주제 디렉토리 아래 정확히 한 단계에 있고 디렉토리와 파일 이름은 정해진 표기를 따른다.
  - frontmatter의 `title`이 존재하며 `**규칙:**` 뒤의 한 문장과 서식 문자를 제외하고 동일하다.
  - 한 파일에는 `**규칙:**` 줄이 정확히 하나만 있다.
  - 마지막 비어 있지 않은 줄은 `‹YYYY-MM-DD HH:MM KST› 출처:` 형식이다.
  - 위반은 파일, 규칙 코드, 기대값과 실제값을 함께 출력하며 하나라도 있으면 종료 코드 1을 반환한다.
- (구성한 예) 검사기는 저장소의 주 언어와 frontmatter parser, test runner로 구현하고 사람이 읽는 기본 출력과 에이전트가 소비하는 `--json` 출력을 함께 제공한다. 패키지 명령으로 노출한 뒤 pre-push와 CI에 연결한다. 정상 경로, 잘못된 경로, 제목 불일치, 출처 누락 fixture를 두어 검사기 자체의 판정도 고정한다.
- (구성한 예) frontmatter 제목과 `**규칙:**` 본문이 다르면 검사기는 두 값을 함께 보여주고 실패한다. 어떤 현재 파일이 위반했는지는 일반 규칙의 사례가 아니라 검사 실행 결과에서 보고한다.

## 비예시

- (구성한 예) “설명은 충분히 명확해야 한다”를 LLM 점수 하나로 판정해 빌드를 차단한다. 명확성의 평가 기준과 결과가 결정적이지 않으므로 사람이나 에이전트의 검토 기준으로 남겨야 한다.
- (구성한 예) 실제 렌더링 로직과 별개의 정규식으로 목록 노출 여부를 흉내 낸다. 지금은 맞더라도 두 구현이 따로 바뀌면 lint가 제품과 다른 판정을 내린다.
- (구성한 예) 위반 여부를 정확히 가릴 수 있는데도 자연어 지침에만 적고 매 작업에서 준수 여부를 에이전트가 다시 추론하게 한다. 규칙을 읽었는지는 알 수 있어도 지켰는지는 보장하지 못한다.

## 적용 범위·예외

다음 세 조건을 모두 만족할 때 lint로 옮긴다.

1. 검사할 입력의 범위를 빠짐없이 열거할 수 있다.
2. 통과와 실패를 코드의 술어로 명시할 수 있다.
3. 같은 입력과 같은 도구 버전에서 반복 실행해도 같은 판정이 나온다.

세 조건을 만족하더라도 위반이 항상 잘못은 아니라면 차단형 오류가 아니라 경고나 상태 보고로 만든다. 의미의 정확성, 설명력, 미적 품질처럼 맥락에 따라 판정이 달라지는 기준은 결정적 검사로 위장하지 않고 검토 절차에 남긴다.

## 확인 방법

1. 규칙의 입력, 기대 결과, 허용 예외를 표로 적는다.
2. 동일한 fixture를 여러 번 실행해 결과와 종료 코드가 같은지 확인한다.
3. 정상 사례와 최소 차이만 있는 위반 사례를 각각 테스트한다.
4. 제품 코드와 같은 판정 로직을 공유하거나, 공유할 수 없다면 제품 동작을 직접 관찰하는 통합 테스트를 둔다.
5. 오류는 CI와 pre-push를 차단하고, 합법적인 상태를 알리는 검사는 경고만 내도록 심각도를 구분한다.
